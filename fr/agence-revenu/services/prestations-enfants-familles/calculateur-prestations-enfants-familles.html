Vous pouvez utiliser ce calculateur pour déterminer les prestations pour enfants et familles auxquelles vous avez droit, ainsi que pour estimer le montant des versements.

Calculer les versements de prestations 

Avertissement : La précision dépend de vos données

Ce calculateur est mis à votre disposition pour vous aider. La fiabilité des résultats dépend de l'exactitude des renseignements que vous entrez.

Énoncé de confidentialité : Nous n'enregistrons aucune des données que vous entrez dans le calculateur

Pensez à effacer l'historique de votre navigateur Internet et à le fermer lorsque vous avez terminé. Bien que nous ne conservions aucune des données que vous entrez, celles-ci restent sur votre ordinateur. Les informations stockées sur votre ordinateur peuvent être consultées par d'autres personnes.

Démarrez votre calcul

En démarrant votre calcul, vous reconnaissez être d'accord avec l’avertissement et l’énoncé de confidentialité.

Ce que vous pouvez calculer

Le calcul prend en compte les prestations pour enfants et familles suivantes :

  • l'allocation canadienne pour enfants (y compris les programmes provinciaux et territoriaux connexes)
  • Allocation canadienne pour l’épicerie et les besoins essentiels (anciennement le crédit pour la TPS/TVH) (y compris les programmes provinciaux et territoriaux connexes)
  • l'avance de l'allocation canadienne pour les travailleurs
  • la Remise canadienne sur le carbone
  • la prestation pour personnes handicapées de Terre-Neuve-et-Labrador
  • la subvention aux personnes âgées propriétaires pour l'impôt foncier de l'Ontario
  • la prestation trillium de l'Ontario (comprend le crédit de taxe de vente de l’Ontario, le crédit d’impôt de l’Ontario pour les coûts d’énergie et l’impôt foncier et le crédit pour les coûts d’énergie dans le Nord de l’Ontario)

Le calcul ne prend pas en compte les montants provenant de :

  • la prestation dentaire canadienne

Renseignements dont vous aurez besoin

Pour en savoir plus sur ce dont vous aurez besoin pour faire le calcul, consultez la page d'aide.
